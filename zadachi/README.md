# Анкета: задачи и программы сотрудника

Страница `https://anketa-lekcii.ru/zadachi/` + приём ответов в Google-таблицу.
Сервер не нужен, всё бесплатно. Анкета обратной связи по лекции лежит в корне того же
домена и этой папкой не затрагивается.

## Что спрашивает анкета

1. **О вас** — ФИО, должность, организация, подразделение, стаж, почта.
2. **Обязанности** — за что отвечаете; кто ставит задачи и кому уходит результат.
3. **Задачи** — главный блок. По каждой задаче: что это, как часто, сколько занимает
   один раз, в каких программах, что получается на выходе, что в ней самое муторное.
   Задачи добавляются и убираются кнопками, изначально три пустых карточки.
4. **Программы** — 14 галочек (Excel, 1С, СЭД, CRM, Консультант+, госпорталы и т. д.),
   поле для отраслевых программ и вопрос, где данные переносят из программы в программу руками.
5. **Что съедает время** — что отнимает больше всего, что делается руками, что отдали бы
   помощнику, свободное поле.

Заполнение — 7–10 минут. Черновик сохраняется в браузере сам, поэтому закрытая вкладка
ничего не теряет.

## Шаг 1. Таблица, куда падают ответы

1. Создайте таблицу на https://sheets.new — например, «Задачи сотрудников».
2. **Расширения → Apps Script**.
3. Удалите содержимое `Код.gs` и вставьте туда весь код из `apps-script.gs`.
4. Сохраните (дискета).
5. **Начать развёртывание → Новое развёртывание**:
   - тип (шестерёнка) — **Веб-приложение**;
   - «Запуск от имени» — **Я**;
   - «У кого есть доступ» — **Все** ← без этого анкета отправлять не сможет.
6. **Развернуть**, разрешить доступ (Google покажет «Приложение не проверено» →
   «Дополнительные настройки» → «Перейти к проекту»).
7. Скопируйте **URL веб-приложения** вида `https://script.google.com/macros/s/AKfy.../exec`.

## Шаг 2. Вписать URL в страницу

В `index.html` найдите строку

```js
const ENDPOINT = "";
```

и вставьте адрес:

```js
const ENDPOINT = "https://script.google.com/macros/s/AKfy.../exec";
```

Закоммитить и запушить — GitHub Pages обновит страницу за минуту.

**Пока `ENDPOINT` пустой, анкета не пропадает:** она скачивается сотруднику файлом Word,
который он присылает письмом. Тот же запасной путь срабатывает, если Google недоступен.

## Что появится в таблице

Два листа, оба создаются сами при первой анкете.

**«Сотрудники»** — строка на анкету: кто, обязанности, программы, что съедает время.

**«Задачи»** — строка на каждую задачу: ФИО, должность, задача, частота, длительность,
программы, результат, что муторно и **≈ часов в месяц**.

Задачи вынесены отдельным листом намеренно: у человека их 5–8, и в одной ячейке они были
бы нечитаемы. Отдельными строками их можно отсортировать по часам и увидеть, на что
уходит время по всей организации, а не только у одного человека.

**«≈ часов в месяц» — прикидка, а не замер:** частота × длительность, обе взяты по нижней
границе выбранного диапазона. Коэффициенты лежат в `apps-script.gs` (`PER_MONTH` и `HOURS`)
и **только там** — на странице анкеты их нет, иначе две оценки одной задачи однажды
разошлись бы. Хотите строже — правьте коэффициенты в одном месте, пересчёт пойдёт со
следующих анкет.

## Ссылка для рассылки

Организация и подразделение подставляются из адреса, чтобы сотрудник их не набирал:

```
https://anketa-lekcii.ru/zadachi/?org=Татэнерго&dept=Бухгалтерия
```

Собрать такую ссылку можно на самой странице: откройте
`https://anketa-lekcii.ru/zadachi/?setup` — появится панель с полями и кнопкой
«Скопировать ссылку». Сотрудникам эта панель не видна.

Кроме `org` и `dept` понимаются `position` и `name`.

## Проверка после правок

`test_form.py` (в рабочем каталоге, не в репозитории) гоняет страницу в настоящем
браузере: 31 проверка — подстановка из ссылки, счётчик задач, добавление и удаление
карточек, обязательные поля, восстановление черновика, запасной файл Word, панель
организатора, отсутствие горизонтальной прокрутки на телефоне.

```
python3 -m http.server 8777          # из корня репозитория
~/playwright-venv/bin/python test_form.py
```
