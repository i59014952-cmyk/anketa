# Анкета обратной связи по лекции

Страница анкеты + приём ответов в Google-таблицу. Всё бесплатно, сервер не нужен.

## Шаг 1. Таблица, куда будут падать ответы

1. Создайте таблицу на https://sheets.new и назовите её, например, «Анкеты лекций».
2. В меню: **Расширения → Apps Script**.
3. Удалите содержимое файла `Код.gs` и вставьте туда весь код из `apps-script.gs`.
4. Сохраните (значок дискеты).
5. Нажмите **Начать развёртывание → Новое развёртывание**.
   - Тип (шестерёнка) — **Веб-приложение**
   - «Запуск от имени» — **Я**
   - «У кого есть доступ» — **Все** ← без этого анкета не сможет отправлять
6. Нажмите **Развернуть**, разрешите доступ (Google покажет предупреждение
   «Приложение не проверено» → «Дополнительные настройки» → «Перейти к проекту»).
7. Скопируйте **URL веб-приложения** — он вида
   `https://script.google.com/macros/s/AKfy.../exec`

## Шаг 2. Вписать этот URL в страницу

В файле `index.html` найдите строку:

```js
const ENDPOINT = "";
```

и вставьте URL:

```js
const ENDPOINT = "https://script.google.com/macros/s/AKfy.../exec";
```

Всё. Теперь каждая отправленная анкета — новая строка в вашей таблице.

## Шаг 3. Ссылка на анкету (GitHub Pages, бесплатно)

1. Создайте репозиторий на GitHub, например `lecture-feedback`, публичный.
2. Загрузите в него `index.html` (кнопка **Add file → Upload files**).
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*,
   ветка `main`, папка `/ (root)`. Сохранить.
4. Через 1–2 минуты страница будет доступна по адресу
   `https://<ваш-логин>.github.io/lecture-feedback/`

Эту ссылку и раздавайте слушателям — QR-кодом на последнем слайде, в чате или в письме.

## Как подставить тему лекции в ссылку

Чтобы человек не заполнял тему, лектора и дату вручную, добавьте их прямо в ссылку:

```
https://<ваш-логин>.github.io/lecture-feedback/?topic=Информационная%20безопасность&lecturer=Иванов%20И.И.&date=13.07.2026
```

Если дату не указать, подставится сегодняшняя.

## Что происходит, если сервер недоступен

Анкета не пропадает: она сохраняется у человека файлом Word, и он может прислать её вам письмом.
Пока `ENDPOINT` пустой, страница работает именно в этом режиме.

## Обновление уже опубликованной страницы

Заменили что-то в `index.html` → загрузите файл в репозиторий заново, GitHub Pages
обновится сам за минуту.
